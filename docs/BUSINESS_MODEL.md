## 5. 🛍️ Sélection des Produits

### 5.1 Critères de sélection d'un produit gagnant

| Critère | Minimum |
|---|---|
| **Prix AliExpress** | 3-30€ |
| **Prix de vente** | 15-80€ |
| **Marge brute** | > 40% |
| **Poids** | < 2kg |
| **Taille** | Petite (pas de frais de port exorbitants) |
| **Avis fournisseur** | 100+ avis positifs |
| **Vidéos produit** | Disponible sur AliExpress |
| **"Won" ou "Hot"** | Badge AliExpress |

### 5.2 Prix de vente — Formule

```
Prix de vente = (Prix AliExpress + Frais de port) × 2.5

Exemple :
- Produit : 8€
- Frais de port : 2€
- Prix de vente = (8 + 2) × 2.5 = 25€
- Marge = 15€ (60%)
```

### 5.3 Produits à éviter

| À éviter | Pourquoi |
|---|---|
| Écrans / LCD | Cassable, retours fréquents |
| Vêtements / Chaussures | Tailles, retours massifs |
| Produits contrefaçon | Légal, ban compte |
| Alimentaire / Cosmétique | Réglementation |
| Batteries lithium | Restrictions transport |
| Gros / Très lourd | Frais de port ruine la marge |

### 5.4 Catalogue initial

| **Semaine 2** | Analyser les vues/ajouts panier |
| **Semaine 3** | Couper les 5 moins performants |

## 8. ⚙️ Opérations & Fulfillment

### 8.1 Processus de commande (automatisé)

```
1. Client achète sur Shopify
         ↓
2. DSers détecte la commande
         ↓
3. DSers commande automatiquement sur AliExpress
         ↓
4. Fournisseur AliExpress expédie (7-20 jours)
         ↓
5. Numéro de suivi récupéré par DSers
         ↓
6. Suivi envoyé au client par email Shopify
         ↓
7. Client reçoit le colis
```

## 10. ⚠️ Gestion des Risques

### 10.1 Matrice des risques

| Risque | Probabilité | Impact | Mitigation |
|---|---|---|---|
| **Fournisseur rupture stock** | Haute | Moyen | Backup fournisseur |
| **Retard livraison** | Haute | Moyen | Communiquer délais clairs |
| **Produit défectueux** | Moyenne | Haut | Sélection rigoureuse |
| **Concurrence prix** | Haute | Moyen | Différenciation branding |
| **Retours massifs** | Moyenne | Haut | Qualité + photos réalistes |

### 10.2 Plan d'action par risque

| Si... | Alors... |
|---|---|
| **Le fournisseur n'a plus de stock** | Basculer sur le backup, prévenir le client |
| **La livraison dépasse 30 jours** | Remboursement partiel ou bon d'achat |
| **Le taux de retour > 10%** | Couper le produit, changer fournisseur |
| **Les Ads ne sont pas rentables** | Tester nouveau produit/nouvelle audience |
